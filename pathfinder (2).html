The Pathfinder's Guide

How does a link or an image find its file? Watch the troupe's d20 travel through the folders, then try it yourself.

What is this?

Every link (href) and image (src) on a website has a path. A path is a set of directions that tells the browser where to find a file. If the directions are wrong, the link goes nowhere or the picture shows up broken.

This page teaches you how to write those directions, using the real files from this website.

  1. Watch. In part 1, pick a scene and press Play. The gold 20 is the browser. It follows the path one step at a time until it finds the file, or fails.
  2. Learn the rules. The four cards in the middle sum up everything the scenes show.
  3. Try it. In part 2, you write the paths yourself and get feedback on each one.

✦ The four path rules

    

      

        
1. Just a name = same folder

        
No slashes means "look right next to me."

        cassian.html
      

      

        
2. folder/ = go into it

        
A folder name and a slash opens that folder.

        img/troupe.png
      

      

        
3. ../ = go up one

        
Climb out of the folder you're in, to the one above.

        ../index.html
      

      

        
4. Capitals must match

        
Online, M and m are different. Copy the name exactly.

        img/Menu-home.png
      

    

    
Every path starts from the folder of the page you are on, not from the top of the site.
