## Path 3 only
**Concept it teaches:** Relative paths: how an href or src finds a file. Same folder, going into a folder (img/), going up a folder (../), and why capital letters have to match.
**Built for how I learn because:** I learn best by seeing something happen and then trying it myself. The tool shows an animation of the browser following a path step by step through my site's folders, then has me write paths myself with feedback.
**Tested by:** Dash Stein **What I changed:** They were confused about what the tool was doing, so I had Claude add aadded a "What is this?" section at the top explaining what a path is and how to use the page, plus a key showing what the d20 and each color on the map mean.
